## CRITICAL GOTCHAS (carry forward)
- **CSS image masks are cross-origin BLOCKED under `file://`** → any CSS image mask MUST be a **data-URI**, never `url(file.png)`. Regular `<img>`/`background-image` fine on file://.
- **Transparent-centre neon border** (used in tramonto Opt3): element `padding:Npx; background:<gradient>; -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0); -webkit-mask-composite:xor; mask-composite:exclude;` — to make the lines RUN, animate the gradient COLOUR via an `@property <angle>`, NOT the element's rotation (rotating the element spins the whole ring).
- **SVG `preserveAspectRatio="none"`** stretches a path to fill its box (used to make the tramonto heartbeat span full width, ends off-screen); default `meet` letterboxes it.
- **CSS custom-prop math needs a UNIT** in keyframes: `calc(var(--x) * -1px)`, not `* -1`.
- **White-on-transparent PNGs** render invisible on white — composite onto a dark bg before viewing.
- Standalone files: **base64-inline the fonts** (Fredoka/Manrope/Chango via `@fontsource` woff2).
- Verify with headless Chromium `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`; Playwright lives at `/opt/node-tools/node_modules` — import as `import pw from '.../playwright/index.js'; const {chromium}=pw`. Element screenshots at 1280 & 390; for a page that autoplays/loops, **clear its intervals/timeouts before calling `_play`** in tests so timed frames aren't polluted. `html{scroll-behavior:smooth}` breaks scripted scroll — set `documentElement.style.scrollBehavior='auto'` first.
